# Lëtzebuergesch Iwwersetzung (lb)

Dëse Projet enthält déi lëtzebuergesch Iwwersetzung fir **SCP: Secret Laboratory**. D’Iwwersetzung gëtt zesumme mat de Spilldateien an der gewielter Sprooch am Spill gelueden.

## Opbau

- `lb/manifest.json` enthält d’Sproochmetadaten.
- D’`.txt`-Dateie enthalen d’Iwwersetzunge vun der Spillinterface.

## Installatioun

1. Kopéier de ganze `lb`-Dossier an den `Translations`-Dossier vun denger SCP:SL-Installatioun.
2. Start d’Spill.
3. Wielt ënner **Astellungen → Interface → Sprooch** d’Sprooch **Lëtzebuergesch** aus.

Standardwee: `Steam\steamapps\common\SCP Secret Laboratory\Translations\lb`

## Matmaachen

Verbesserunge fir d’Iwwersetzung si wëllkomm. Änner d’entspriechend `.txt`-Datei a loosst d'Schlësselen, Zeiluerdnung, Markéierungen a Plazhalter onverännert.

## Sproochcodes

- Interface: `lb`, `lb-LU`
- System: `lb`, `lb-LU`

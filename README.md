# Lëtzebuergesch Iwwersetzung (lb)

Dësen Ordner enthält déi offiziell **Lëtzebuergesch Iwwersetzung** fir **SCP: Secret Laboratory**.

## Wat ass dat?

Dës Iwwersetzung mécht déi ganz Spillinterface op Lëtzebuergesch verfügbar. De Spillclient sicht am Dossier `Translations` no een Sproochen-Ordner an läscht d'Iwwersetzung automatesch, jee no der am Spill gewielter Sprooch.

## Struktur

- `manifest.json` - Metadaten vun der Sprooch (Numm, Auteure, Locales)
- `*.txt` - Iwwersetzungstexter. Format: `Käfeg~Text` (fir wéi Items) oder einfach eng Textzeil pro Zeil.

## Installatioun

1. De kompletten `lb`-Ordner an den Ordner `Translations` vun Ärer SCP:SL Installatioun kopéieren.
2. D'Spill starten.
3. Ënnert **Settings → Interface → Sprooch** op **Lëtzebuergesch** wiesselen.

> Standard-Pad: `Steam\steamapps\common\SCP Secret Laboratory\Translations\lb`

Dës Iwwersetzung gouf deelweis mat Hëllef vun AI generéiert an deelweis vum Ersteller selwer geschriwwen an iwwerschafft. De Repository gouf vum Ersteller erstallt, an e groussen Deel vum Code an den Inhalter gouf och vum Ersteller selwer entwéckelt a geschriwwen.

Wann Dir Verbesserunge fannt oder bäidroe wëllt, kënnt Dir déi entspriechend `.txt`-Dateien einfach änneren.

# Luxembourgish Translation (lb)

This folder contains the official **Luxembourgish translation** for **SCP: Secret Laboratory**.

## What is this?

This translation makes the entire game interface available in Luxembourgish. The game client looks for a language folder inside the `Translations` directory and automatically loads the translation based on the language selected in the game.

## Structure

* `manifest.json` - Language metadata (name, authors, locales)
* `*.txt` - Translation files. Format: `Key~Text` (for items, etc.) or simply one text line per line.

## Installation

1. Copy the complete `lb` folder into the `Translations` folder of your SCP:SL installation.
2. Start the game.
3. Go to **Settings → Interface → Language** and select **Luxembourgish**.

> Default path: `Steam\steamapps\common\SCP Secret Laboratory\Translations\lb`

## Team

This translation was created partially with the assistance of AI and partially written and revised by the creator. The repository was created by the creator, and a large portion of the code and content was also independently developed and written by the creator.

If you find any improvements or would like to contribute, you can simply edit the corresponding `.txt` files.

* Interface: `lb`, `lb-LU`
* System: `lb`, `lb-LU` (ISO code for Luxembourgish)

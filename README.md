# Lëtzebuergesch Iwwersetzung (lb)

Dësen Ordner enthält déi offiziell **Lëtzebuergesch Iwwersetzung** fir **SCP: Secret Laboratory**.

## Wat ass dat?

Dës Iwwersetzung mécht déi ganz Spillinterface op Lëtzebuergesch verfügbar. De Spillclient sicht am Dossier `Translations` no een Sproochen-Ordner an läscht d'Iwwersetzung automatesch, jee no der am Spill gewielter Sprooch.

## Struktur

- `manifest.json` - Metadaten vun der Sprooch (Numm, Auteure, Locales)
- `*.txt` - Iwwersetzungstexter. Format: `Käfeg~Text` (fir wéi Items) oder einfach eng Textzeil pro Zeil.

## Installatioun

1. De kompletten `lb`-Ordner an den Ordner `Translations` vun Ärer SCP:SL Installatioun kopéieren.
2. D'Spill starten.
3. Ënnert **Settings → Interface → Sprooch** op **Lëtzebuergesch** wiesselen.

> Standard-Pad: `Steam\steamapps\common\SCP Secret Laboratory\Translations\lb`

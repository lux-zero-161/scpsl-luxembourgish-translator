# Luxembourgish Translation (lb)

This folder contains the official **Luxembourgish translation** for **SCP: Secret Laboratory**.

## What is this?

This translation makes the entire game interface available in Luxembourgish. The game client looks for a language folder inside the `Translations` directory and automatically loads the translation based on the language selected in the game.

## Structure

* `manifest.json` - Language metadata (name, authors, locales)
* `*.txt` - Translation files. Format: `Key~Text` (for items, etc.) or simply one text line per line.

## Installation

1. Copy the complete `lb` folder into the `Translations` folder of your SCP:SL installation.
2. Start the game.
3. Go to **Settings → Interface → Language** and select **Luxembourgish**.

> Default path: `Steam\steamapps\common\SCP Secret Laboratory\Translations\lb`

## Team

This translation was created partially with the assistance of AI and partially written and revised by the creator. The repository was created by the creator, and a large portion of the code and content was also independently developed and written by the creator.

If you find any improvements or would like to contribute, you can simply edit the corresponding `.txt` files.

* Interface: `lb`, `lb-LU`
